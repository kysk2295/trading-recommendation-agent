# 한국 데이트레이딩 에이전트 운영 안내

이 서비스는 한국 주식시장을 읽고 연구·가상 체결 결과를 남긴다. KIS, LS, OpenDART에는 주문·계좌·잔고·포지션 변경 요청을 보내지 않는다. 화면의 `ARMED`와 `ACTIVE`는 각각 조건부 가상 진입 계획과 가상 체결 상태이며 실제 주문이 아니다.

## 사용자가 보는 상태

| 상태 | 의미 | Hermes 알림 |
|---|---|---|
| `INVESTIGATING` | 근거를 더 확인하는 중 | 보내지 않음 |
| `ARMED` | 진입 조건·손절·목표가가 확정된 가상 계획 | 최초 1회 |
| `ACTIVE` | 최신 완료 봉에서 조건이 충족되어 가상 체결됨 | 기존 알림의 답글 1회 |
| `REJECTED` / `BLOCKED` / `EXPIRED` | 근거 부족, 안전 차단 또는 유효기간 종료 | 기존 `ARMED`가 무효화될 때만 답글 |
| `STOPPED` / `TARGETED` / `CENSORED` | 손절, 목표가, 또는 증거 부족에 따른 가상 종료 | 기존 알림의 답글 1회 |

`ARMED`와 `ACTIVE`에는 판단 시각, 진입 또는 트리거, 손절, 목표가, 근거, 무효화 조건, 유효기간, `SHADOW/PAPER ONLY` 표시가 모두 있어야 한다. 값이 없으면 추정해서 채우지 않고 차단 상태로 남긴다.

## 장중 운영 흐름

1. 한국시장 자료 수집 서비스가 현재 세션의 완료 봉, 호가, 테마·뉴스·거래대금 근거를 기록한다.
2. `ai.trading-agent.kr-day-session`이 120초마다 새 완료 봉을 확인한다.
3. 발견된 각 종목은 다음 주기 안에 조사중, 조건부 계획, 기각, 차단 또는 만료 중 하나로 기록된다.
4. 새 종목이 없어도 기존 `ACTIVE` 가상 포지션은 계속 관리한다.
5. 같은 상태가 반복되면 원장 재생으로 처리하고 Hermes 메시지를 추가하지 않는다.
6. 대시보드와 Hermes는 같은 결정·가상체결 원장에서 상태를 읽는다.

세션 종료, 오래된 자료, 현재 날짜가 아닌 자료, 누락된 스프레드에서는 새 추천을 만들지 않는다. 같은 봉에서 손절과 목표가가 동시에 닿으면 손절로 처리한다.

## 장 시작 전 확인

- 배포된 프로젝트가 `main` 브랜치의 설정된 정확한 커밋인지 확인한다.
- 한국 자료 수집, 120초 세션, 대시보드 발행, Hermes 전달, 장 마감 서비스가 로드됐는지 확인한다.
- 한국 세션 캘린더가 오늘을 XKRX 거래일로 표시하고 관찰 시각이 현재보다 미래가 아닌지 확인한다.
- 최근 health 기록에서 자료 계약과 서비스 상태를 확인한다.
- KIS·LS 제공자 변경 작업 수가 0인지 확인한다.

이 확인 중 하나라도 실패하면 임계값을 낮추거나 시간을 바꾸지 않는다. 원인을 고친 뒤 다음 정상 완료 봉을 기다린다.

## 장중 인수 확인

첫 정상 완료 봉 이후 다음 항목을 확인한다.

- 자료 health가 현재 세션과 일치한다.
- 발견된 모든 종목에 120초 안에 사유가 있는 결정이 생긴다.
- 변하지 않은 `INVESTIGATING`은 다음 완료 봉에서 해소된다.
- 동일 상태 10회 재생에도 Hermes 추가 메시지가 없다.
- `ARMED`는 조건부 계획이며 체결로 표시되지 않는다.
- 자연스럽게 진입 조건이 충족된 경우에만 `ACTIVE`가 생긴다.
- 대시보드 상태·시각과 Hermes 스레드가 같은 원장 이벤트를 가리킨다.
- KIS·LS 변경 작업 수는 계속 0이다.

검증을 위해 신호를 만들거나 가격·거래량·스프레드 기준을 완화하지 않는다.

## 장 마감과 학습 루프

`ai.trading-agent.kr-day-close`는 15:40, 16:10, 18:00 KST에 실행된다. 첫 유효 실행이 그날의 마감 보고서, 학습 정책, Hermes 일일 요약, 완료 영수증을 기록한다. 뒤의 실행은 정확한 재생이어야 한다.

학습 루프는 다음 원칙을 지킨다.

- 가장 신뢰도가 낮은 한 단계만 실패 가설로 선택한다.
- 한 보고서에서 다음 세션용 `SHADOW` challenger를 최대 1개 만든다.
- 현재 Champion은 직접 바꾸지 않는다.
- 한 번의 좋은 결과나 표본 부족 결과로 승격하지 않는다.
- 사전 등록된 최소 관찰 수, 안전 증거, 동일 위험 한도, 다중검정 예산이 모두 충족돼야 승격 검토가 가능하다.

## 장애 대응

- 자료가 오래됨: 새 추천을 차단하고 수집 health부터 확인한다.
- 스프레드 또는 완료 봉 누락: 값을 추정하지 말고 해당 종목을 차단한다.
- 결정 원장과 가상체결 원장 불일치: 해당 시장 대시보드를 `corrupt`로 격리하고 원본 파일을 수정하지 않는다.
- Hermes 장애: 원장 상태는 유지하며 같은 이벤트 ID로 재전송한다.
- 장 마감 재시작: 이미 존재하는 완료 영수증과 보고서 ID를 재생하고 중복 요약·challenger를 만들지 않는다.

실제 주문, 계좌 조회, 잔고 조회 또는 포지션 변경이 필요한 대응은 이 한국시장 서비스의 범위 밖이다.
