# G003 Primary production-source admission contract

- The observable inspection surface is `run_research_agent_primary_sources.py inspect --config <private-service-config> --now <aware-ISO-8601>`. It loads only the configured local source paths, invokes no provider, network, broker, or mutation surface, and prints one redacted canonical JSON object.
- The JSON contains exactly the ordered Primary families `opportunity_manager`, `market_context`, and `day_trading`; each family reports `ready` or `blocked`, its source key, and immutable SHA-256 provenance digests. The top-level `broker_mutation` is always `0`; no filesystem path, credential, account identifier, or raw source payload is emitted.
- Admission uses the supplied aware time and the repository's tracked XNYS calendar. Outside the NY regular session every family emits its own `*.blocked.session_closed` evidence without opening source artifacts.
- During an open session, only the current New York date is admissible. Missing artifacts emit `opportunity.blocked.snapshot_unavailable`, `market_context.blocked.snapshot_unavailable`, or `day.blocked.source_pair_unavailable`; an available prior-session artifact emits the corresponding `*.blocked.prior_date` evidence.
- Opportunity Manager admits only the latest current-session snapshot whose snapshot, evidence-reference, and source-coverage timestamps are not future or prior-date, whose `valid_until` has not elapsed, and whose candidates each carry finite nonnegative `spread_bps`. Expected gaps emit `opportunity.blocked.stale` or `opportunity.blocked.missing_spread`.
- Market Context admits the latest mode-600 current-date `MarketContextSnapshot` when its snapshot and coverage provenance is not future or prior-date and its `valid_until` has not elapsed. The production breadth feature contract does not contain quote spread, so Market Context has no spread gate. Expected gaps emit `market_context.blocked.stale` or `market_context.blocked.prior_date`.
- Day Trading requires the current `YYYYMMDD` session's mode-600 regular `paper_recommendations.sqlite3` and mode-600 regular `market_risk_screen.csv` together. It binds logical database counts/latest completed checkpoint plus SHA-256 digests of both files into one evidence payload. The latest completed checkpoint and latest risk rows must be current-date, non-future, and no older than the local typed three-minute Primary freshness limit; latest risk rows must all contain finite nonnegative spreads. Expected gaps emit `day.blocked.completed_bar_unavailable`, `day.blocked.stale`, `day.blocked.prior_date`, or `day.blocked.missing_spread`.
- Structurally malformed, unsafe, or unreadable present sources remain typed `*_source_invalid` failures. Expected readiness gaps remain evidence so the runtime can deterministically persist `no_action` with zero model and broker calls.
